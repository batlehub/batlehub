# Every API operation, and whether perf/scripts/profile.sh profiles it.
#
# One line per operation: `METHOD /path<TAB>profiled` or `METHOD /path<TAB>skip: <reason>`.
# The path is the OpenAPI spelling (constraints dropped, `}/@` as `}@`).
#
# `profiled` means a soak arm (perf/k6/soak_arms.js) reaches the route — measured
# by the router during the profile run, not inferred from a URL. Two gates hold it:
#   crates/web/tests/profile_route_coverage.rs  every PR: each operation named once, none stale
#   perf/scripts/profile_report.py              a profile run: `profiled` ⇔ actually reached
#
# To profile a route: add an arm that reaches it, then flip its line to `profiled`.
